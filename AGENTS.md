# Barter: старт работы

Перед задачами в этом репозитории прочитай:

1. `ROADMAP.md`: актуальная очередь, опубликованное, незакрытые проверки.
2. Верхнюю актуальную запись `HANDOFF.md`.
3. `docs/PRODUCT_VISION.md`: цель, приоритеты и ограничения.
4. Для UI: `docs/DESIGN_STANDARD.md`; затем инструкции затронутого каталога.

На «продолжаем» бери первый незакрытый пункт ROADMAP, если пользователь не задал
другую задачу. Проверяй master, PR и dirty worktree до правок; не сбрасывай чужие
изменения. Не повторяй опубликованную работу по устаревшим записям HANDOFF.

После рабочего блока обновляй ROADMAP и HANDOFF: что изменено, проверки,
ограничения, PR/commit и один следующий шаг. При необходимости обновляй BACKLOG.
Различай реализованное, опубликованное и реально проверенное. Не отмечай
авторизованные/iPhone-сценарии проверенными по одному build или unit-тестам.

Яндекс ID, новые карты и платежи отложены до отдельного сигнала Максима.
Для UI сохраняй единый стандарт и исходную геометрию мобильного хаба.
ROADMAP не даёт новых разрешений на внешние действия или ослабление защиты.
