# БАРТЕР · Сообщения · утверждённый референс (20.10.2026)

**Оригинал референса:** Библиотека ChatGPT → `/Barter/Design References/approved-messages-inbox-2026-10-20.png` (полный PNG).

**Статус:** APPROVED. Обязательный дизайн-контракт для мобильной страницы `/messages` и её дальнейших изменений. Макет утверждён в разговоре 20 октября 2026 года под названием **«экран_сообщений_barter_с_обновлённой_навигацией.png»** (941×1672).

## Список диалогов (главный эталон)
- Светлый холст, типографика чёрная, вторичный текст холодно-серый, акцент **#FF5A0A**.
- Верхний заголовок «Сообщения», действия справа: «…» и контурное перо для начала диалога. У перезаполненной иконки есть рабочее назначение: выбирать объявление из поиска; отдельного сервера «пустых» диалогов нет.
- Поиск внутри мягкой светло-серой плашки. Фильтры: **Все**, **Покупка**, **Обмен** (не путать с моей ролью покупателя/продавца). Фильтр непрочитанных находится в меню «…».
- Список: квадратная фотография связанного товара 56×56 с радиусом 13; рядом имя собеседника, предмет обсуждения, превью 1–2 строки; справа время, вид сделки и непрочитанное. Бейдж непрочитанного **не накладывать на изображение товара**.
- «Покупка» нейтральная, «Обмен» с оранжевой иконкой Repeat2. Если объявление поддерживает оба режима, оно попадает в обе вкладки.
- Низ: **существующий фирменный LiquidBottomNav** с 4 ссылками и **круглым оранжевым Bubble B** по центру. Не заменять его `+`, не копировать второй навбар внутрь страницы.

## Открытая переписка
Отдельные одобренные экраны из разговора: `чат_о_продаже_iphone_15_pro.png`, `чат_об_обмене_macbook_на_iphone.png`, `детали_контакта_в_маркетплейс_чате.png`. Сохраняются реальные API-чаты, загрузка сообщений, сокеты, отправка, вложения, предпросмотр объявления, статус прочтения, быстрые ответы и помощь. Открытая переписка занимает весь экран и **не отображает нижнюю панель**. Входящие пузыри серые, исходящие оранжевые с белым текстом.

## Приёмка
- Mobile-first: CSS 393×852, проверить 375px и 430px, Safari PWA + обычный Safari, светлую и тёмную темы.
- Навбар остаётся у нижней границы приложения; никаких смазанных слоёв, двойных safe-area или всплывающих поверх клавиатуры панелей.
- Не подменять рабочие диалоги демонстрационными именами из изображения; референс задаёт композицию, данные только из API.
- Не утверждать «попиксельно 1:1», пока не снят и не сравнен скриншот живого iPhone с макетом при совпадающем размере и масштабе.

### Реализация
`apps/web/src/app/messages/page.tsx`, `apps/web/src/app/messages/messages-approved.css`, `apps/web/src/lib/chat-list.ts`. При следующем рефакторинге использовать этот документ как источник истины.

- Для двухрежимных объявлений в списке показывать **короткий бейдж активной вкладки**: «Покупка» в фильтре покупки, «Обмен» в общем списке или фильтре обмена; полное описание режима остаётся в карточке объявления/диалоге.
