# Barter — визуальные референсы и ассеты, октябрь 2026

Этот каталог содержит согласуемое **дизайн-направление**, архив макетов и
изображения категорий для объявлений **без фотографий**.

Начните с [VISION_AND_IMPLEMENTATION.md](VISION_AND_IMPLEMENTATION.md), затем
откройте [ASSET_CATALOG.md](ASSET_CATALOG.md).

- `screens/refined-v2/` — предпочтительные 10 отдельных iPhone-экранов.
- `screens/concept-v1/` — предыдущая серия, хранится для истории решений.
- `screens/initial-overview.webp` — ранний сводный concept board.
- `assets/branding/` — логотип: светлый/тёмный wordmark и отдельный знак.
- `assets/placeholders/` — тематические иллюстрации для карточек без фото.
- `asset-manifest.json` — машиночитаемые пути, размеры, SHA-256 и класс ассета.

**Важно:** изображения являются референсами; не считайте нарисованные на них
данные реальными. В текущей ветке мы ничего не меняем в работающем приложении.
Логотип в слове «БАРТЕР» — только кириллицей. Кнопка Bubble B выполняет
функцию «Создать объявление», а не является просто декорацией.

Оригинальные источники генерировались в чате в PNG; здесь хранятся удобные
WebP-версии высокого качества. Перерисовывать их агенту не требуется.
