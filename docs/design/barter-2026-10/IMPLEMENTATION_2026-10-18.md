# Реализация визуального референса Claude: статус 18 октября 2026

Исходник для сравнения: файл `barter-mobile.html` пользователя, а также утверждённые изображения `docs/design/barter-2026-10/screens/refined-v2/`.
**Этот PR — первый рабочий интеграционный срез, не принятие всего интерфейса 1:1.**

## Реально изменено
- Единый бренд: на главной используются оригинальные изображения знака и кириллического wordmark из HTML Клода (`/brand/claude-mark.png` и `/brand/claude-word.png`), в центральной кнопке — белый фирменный знак.
- Нижний док на телефоне: четыре рабочих маршрута по краям, фирменная кнопка публикации в центре вместо «+»; меню `sale/barter/both` сохранено.
- Главная: компактная двухрядная шапка, режим каталога, скруглённые bubble-категории, промоблок и карточки в едином оранжевом языке. Карточки получают только реальные ответы API.
- Иллюстрации: WebP из уже утверждённого набора (12 шт) физически скопированы в `apps/web/public/visual-refresh/placeholders/`; fallback покрывает спецтехнику, услуги и неизвестные категории.
- Профиль, чат, карточка товара, форма публикации, аналитика: общие стилевые правила без подмены бизнес-логики.

## Что обязательно проверить
- `npm run build --workspace @app/web` и web regression tests в CI.
- Browser acceptance: 390px light/dark и desktop 1440px; заметный белый док, правильные отступы категорий и баннера; iOS Safari + PWA отдельно.
- Избранное, галерея жестами, переходы, форма публикации, чат, профиль и авторизация с **реальными** данными.
- Новый логотип — SVG-перерисовка формы по присланному референсу; ручная векторная/товарно-знаковая проверка и iOS PNG-иконки ещё не выполнены.
- На мобильной главной используется оригинальное изображение баннера Клода (отдельные светлый и тёмный варианты); десктоп сохраняет адаптированный иллюстрированный баннер. Визуальная сверка десктопа ещё не завершена.
- Сравнение пикселей с референсом пока не выполнено; утверждение «1:1» **не подтверждено**.

## Принципы
- Нельзя заменять реальный API демо-данными или создавать фиктивные сделки.
- Не удалять пользовательскую функциональность при редизайне.
- Не мержить до зелёного CI и визуальной приёмки.
- Перед запуском на реальном iPhone проверить safe-area, home indicator, положение дока, клавиатуру и работу фото.

## Продолжение после восстановления переписки, PR #76

- **Карточка объявления:** добавлены работающие доступные индикаторы фото (переключение кнопками при свайпе), галерея, параметры и мобильный информационный блок приближены к HTML-референсу; основные действия закреплены снизу с учётом safe-area. Работающие маршруты связи сохранены; прямого онлайн-платежа не имитируем.
- **Чат:** отдельно сверены и обновлены шапка собеседника, карточка связанного объявления, пропорции сообщений и нижний composer. Синий маркер режима продажи заменён нейтральным, обмен остаётся оранжевым.
- **Профиль:** компоновка аватара, статистики и мобильного меню адаптирована к референсу; настоящие счётчики и действующие разделы сохранены. Раздел списка объявлений исключён из CSS изменений профиля.
- **Браузерный QA:** добавлена отдельная фикстура объявления с двумя фотографиями, проверка интерактивных точек галереи, нижней контактной панели и отсутствия перекрывающего дока.
- **Незакрытые вопросы:** полный визуальный diff каждого внутреннего экрана в 360/390/440 и обеих темах, валидация реальных сообщений и избранного, физический Safari/PWA на iPhone, проверка поведения галереи на прокрутке и с клавиатурой.
- **Статус выпуска:** PR остаётся draft. Нет подтверждения полной пиксельной идентичности, в production ничего не отправляем до прохождения CI и приёмки.
