# Реализация визуального референса Claude: статус 18 октября 2026

Исходник для сравнения: файл `barter-mobile.html` пользователя, а также утверждённые изображения `docs/design/barter-2026-10/screens/refined-v2/`.
**Этот PR — первый рабочий интеграционный срез, не принятие всего интерфейса 1:1.**

## Реально изменено
- Единый бренд: в шапке и кнопке публикации используется новый оранжевый SVG `/brand/bubble-b-v3.svg`, в качестве кириллического словесного знака — текст «БАРТЕР».
- Нижний док на телефоне: четыре рабочих маршрута по краям, фирменная кнопка публикации в центре вместо «+»; меню `sale/barter/both` сохранено.
- Главная: компактная двухрядная шапка, режим каталога, скруглённые bubble-категории, промоблок и карточки в едином оранжевом языке. Карточки получают только реальные ответы API.
- Иллюстрации: WebP из уже утверждённого набора (12 шт) физически скопированы в `apps/web/public/visual-refresh/placeholders/`; fallback покрывает спецтехнику, услуги и неизвестные категории.
- Профиль, чат, карточка товара, форма публикации, аналитика: общие стилевые правила без подмены бизнес-логики.

## Что обязательно проверить
- `npm run build --workspace @app/web` и web regression tests в CI.
- Browser acceptance: 390px light/dark и desktop 1440px; заметный белый док, правильные отступы категорий и баннера; iOS Safari + PWA отдельно.
- Избранное, галерея жестами, переходы, форма публикации, чат, профиль и авторизация с **реальными** данными.
- Новый логотип — SVG-перерисовка формы по присланному референсу; ручная векторная/товарно-знаковая проверка и iOS PNG-иконки ещё не выполнены.
- Новое изображение hero не тождественно исходному баннеру Клода (сохранена существующая иллюстрация ноутбука): это видимое отличие, подлежащее финальной сверке.
- Сравнение пикселей с референсом пока не выполнено; утверждение «1:1» **не подтверждено**.

## Принципы
- Нельзя заменять реальный API демо-данными или создавать фиктивные сделки.
- Не удалять пользовательскую функциональность при редизайне.
- Не мержить до зелёного CI и визуальной приёмки.
- Перед запуском на реальном iPhone проверить safe-area, home indicator, положение дока, клавиатуру и работу фото.
