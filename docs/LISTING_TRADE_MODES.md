## Контракт и совместимость

- saleEnabled=true/barterEnabled=false: Маркет; false/true: Бартер; true/true: обе ленты.
- false/false, null, строки вместо boolean и конфликт с attributes.isBarter отклоняются.
- Старые клиенты могут передавать attributes.isBarter. Новые поля канонические;
  alias сохраняется для совместимости. SQL trigger поддерживает старые writers
  во время выпуска. Старые версии API не подходят для отката после появления
  exchange-only: они не умеют фильтровать Market по новому полю.
- Перед сохранением web проверяет /listings/capabilities. Старый API не должен
  молча принять публикацию, отбросив неизвестные поля. Данные остаются в форме.
- Существующая политика категорий сохраняется, включая отсутствие обмена
  у вакансий. Межкатегорийный обмен вещей не запрещается этой моделью.
- Market Meilisearch сохраняет текущий путь: сначала ограниченное окно id,
  затем проверка актуальных полей PostgreSQL, подсчёт и пагинация. Данные индекса
  не дают допуск в другую ленту. Barter пока использует PostgreSQL-поиск.
- Новый алгоритм ранжирования взаимных интересов не подменяется старым скорингом;
  он будет добавлен после структурированных пожеланий.
