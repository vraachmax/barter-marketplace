# Подгонка отступов, 2026-09-26

## Основание и границы
Запрос Максима: закончить анализ отступов и подгонку интерфейса до разбора
barter_chat_export.txt. Проверен master 2e5de9c7, открытых PR не было.
На production главная дважды показала timeout, тарифы остались в skeleton.
Это не полная визуальная приёмка наполненного production и не исправленный backend.
Геометрия ниже установлена по исходникам; итог проверяется на изолированных
браузерных фикстурах. Физический iPhone и его клавиатура остаются вне проверки.

## Сравнение с первичными источниками
- https://fluent2.microsoft.design/layout: базовый шаг 4px, близость групп,
  выравнивание и адаптивные поля, допустимы оптические исключения.
- https://developer.apple.com/design/tips/: выравнивание, отсутствие обрезки,
  сохранение пропорций изображений, рекомендуемая область касания 44x44pt.
Источники прочитаны 26 сентября. pt, dp и CSS px не отождествляем.
16/24px полей и 32/48px секций ниже являются решением Barter, а не предписанием Apple.

## Изменения
| Экран | Было | Стало |
|---|---|---|
| Тарифы | Шапка max768, содержимое max1152; поля 16 вместо 24 на desktop | Шапка и содержимое max1152, поля 16/24 |
| Тарифы | Между секциями 48/64/56, разные промежутки карточек | Секции 32 mobile / 48 desktop, сетки 16, карточки 16/24 |
| Поиск | Поля 12/16, строка фильтров без общего max-width | Поля 16/24, общий max768, строка шапки минимум64 |
| Кошелёк | Шапка max768, содержимое max1024, ошибка max768 | Все состояния max1152 с полями16/24 |
| Главная, поиск, объявления, тарифы, профиль, настройки, кошелёк | Запас страницы96–128 плюс body72; в старом профиле ещё112 | Один запас116+safe-area на mobile,40 на desktop; вложенный запас удалён |

Нижний хаб: геометрия, пузырь, анимация сохранены. 116px учитывает 12px нижнего
отступа +66px панели +20px выступа пузыря +18px свободного места.
Legacy body reserve отключается только на страницах с page-content-spacing.
Остальные страницы не мигрированы. На breakpoint768 хаб скрыт и mobile-reserve отсутствует.
Кнопки 44/48/52 сохранены; кнопка фильтров в поиске получила минимум44.
Выравнивание переключателя Market/Barter и невыходящая метка тарифов уже были
исправлены PR26: повторно их не перерабатываем.

## Проверка
Расширена существующая suite listings-layout-acceptance: реальные DOM-границы
шапки/содержимого, поля, нижний запас, отсутствие второго body-reserve и overflow,
отступы секций, оба состояния кошелька. Снимки pricing-top, wallet, search дополняют
listings/pricing/catalog. Фикстуры, без реальных аккаунтов и платных операций.
Результат CI/публикации фиксируется в HANDOFF после проверки.
