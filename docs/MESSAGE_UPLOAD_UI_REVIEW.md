# UI-02: ожидание загрузки вложения

PR #29, test/socket-conversation-acceptance. Не опубликовано.

## Поведение

apiUploadFile принимает необязательный signal и передаёт его в fetch.
Экран сообщений задаёт AbortSignal.timeout(60000) для multipart отправки.
Ограничено ожидание запроса вместе с чтением ответа. Как и прочие клиентские
таймеры браузера, deadline может приостанавливаться в неактивной вкладке.
Другие вызовы upload сохраняют прежнее поведение.

При таймауте используется существующее состояние неоднозначного исхода:
«Нет подтверждения отправки», кнопка обновления переписки, сохранённые текст/файл.
finally снимает busy; автоматических повторов нет.
Отмена клиентского ожидания не отменяет гарантированно серверную запись.
Вложения пока не имеют ключа идемпотентности, явный повтор может создать дубль.

## Браузерная приёмка

Расширена apps/web/tests/browser/messages-acceptance.mjs:
- настоящий file input, FormData и fetch; multipart содержит имя файла и подпись;
- ответ 503 сохраняет текст/файл в исходном чате, явный успешный повтор очищает их;
- двойное нажатие создаёт один upload, запоздалый успех не очищает другой чат;
- native AbortSignal отменяет зависший fetch, busy снимается, черновик остаётся;
- фикстура завершает серверную запись уже после отмены клиентом; обновление истории
  и переходы между чатами не запускают повторную загрузку и не удаляют черновик.

Тестовая addInitScript ускоряет только timeout(60000) до 800ms, только когда
сценарий явно включает флаг. Проверяет, что приложение запросило 60000ms.
Используется настоящий нативный AbortSignal, не подмена результата fetch.
Не измеряет 60 секунд реального ожидания и поведение фоновой вкладки.

6 конфигураций: WebKit 360/440 и Chromium 1280, обе темы, production-сборка Next.
HTTP/auth/history фикстуры, WebSocket отключён. Новые screenshots:
*-upload-timeout.png в messages-browser-evidence.
Не проверены настоящая доставка медиа/Vercel Blob, browser cookie/reconnect,
реальные аккаунты, физический iPhone и клавиатура. API-проверки описаны отдельно
в docs/MESSAGE_MEDIA_REVIEW.md. Изменений визуальной геометрии нет.
