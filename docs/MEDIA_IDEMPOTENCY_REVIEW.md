# UI-02: идемпотентность вложений

PR #29. Выпуск разрешён Максимом сообщением «Делай и публикуй».

## Контракт

Multipart /chats/:id/media принимает необязательный UUIDv4 clientMessageId.
Клиент сохраняет ключ по чату вместе с File-объектом и нормализованной подписью
в памяти страницы. Сбой/таймаут и переходы между чатами не меняют ключ.
Подтверждённая отправка или изменённый файл/подпись начинают новую операцию.
Reload теряет черновик/ключ; повторный выбор файла считается новой операцией.

На сервере ключ связан с chatId/userId через прежний msg_v1_ SHA-256 ID.
Текстовый и media endpoint разделяют пространство ключей: подмена вида сообщения
возвращает 409. Проверка участника выполняется до replay.
mediaFingerprint хранит SHA-256 байтов и нормализованного заявленного MIME.
Повтор должен совпасть по fingerprint, mediaType и нормализованной подписи.
Имя файла не участвует: оно не меняет содержимое. Это не проверка сигнатуры/декодирования.

До upload выполняется поиск повтора. Уже сохранённое сообщение возвращается без
нового файла/события/автоответа/аналитики/readAt/updatedAt. При гонке уникальный PK
PostgreSQL оставляет одного победителя. После rollback P2002 читается победитель,
проигравший запрос удаляет только свой уникальный URL. Сбой cleanup логируется;
фонового сборщика orphan-файлов пока нет. Крах процесса между upload и commit
может оставить файл. Ключ не делает доставку Socket.IO exactly-once:
durable outbox отсутствует; пропуски восстанавливаются чтением истории.

## Миграция и совместимость

Не удаляет/не переписывает старые данные. Старые клиенты без ключа работают как

## Проверки

Media suite расширена с 8 до 13 групп:
повтор без upload/side effects, конфликт подписи/байтов/MIME/text↔media,
невалидный ключ/посторонний/case/sender scope, 10 параллельных запросов с барьером,
новая операция/legacy. У гонки проверяются одна запись/событие/автоответ и удаление
9 лишних файлов с сохранением файла победителя. Настоящие Nest/multipart/PG/local disk,
auth guard тестовый. Прежние проверки ошибок upload/save/delete сохранены.

Browser suite расширена до 11 групп на конфигурацию. После native abort фикстура
сохраняет сообщение, переходы между чатами и явный повтор сохраняют ключ и одну
запись; подтверждённая новая отправка получает новый ключ. API/auth фикстуры,
WebSocket отключён. Deadline ускорен test-only до 800ms, приложение задаёт 60 сек.
WebKit 360/440 и Chromium 1280, обе темы. Не физический iPhone.

## Открытая приёмка после выпуска

Browser cookie/reconnect, физический iPhone/клавиатура и настоящие аккаунты,
доставка/воспроизведение Vercel Blob не подтверждены. Production health был
недоступен из текущей среды; запрещённые старые попытки не повторяются.
