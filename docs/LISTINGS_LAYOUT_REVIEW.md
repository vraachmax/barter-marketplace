# Проверка списка объявлений, тарифов и переключателя каталога

## Изменения PR #26

- /listings использует общий AccountScreenHeader и единую адаптивную компоновку.
  Три равные статусные вкладки со счётчиками, общие карточки и действия.
- /profile/listings перенаправляет на канонический /listings, сохраняя группу статуса.
- Метки тарифа «Рекомендуем» и пакета находятся в потоке, без отрицательного top.
- Маркет/Бартер и пояснение центрированы; индикатор выбранного режима проверяется отдельно.
- Исходный мобильный хаб, backend и платёжные интеграции не менялись.

## Область автоматизированной проверки

Production webpack build. WebKit 360/440 и Chromium 820/1280, каждая ширина в
светлой и тёмной теме. SSR API на loopback; auth и клиентские API заменены
изолированными фикстурами. Реальных публикаций, сообщений или списаний нет.

Проверяются общий заголовок 18px/600 и высота шапки, вкладки не ниже 44px,
длинный заголовок карточки без выхода за границы, канонический redirect,
вкладки/история/reload, открытие и отмена редактора, публикация и восстановление
только на фикстурах, диалог продвижения с нулевым балансом без платежа,
положение метки внутри карточки и обрезающих предков, центры переключателя
и его индикатора, сохранение сортировки, повтор после 503 и возврат после входа.

Предыдущие неуспешные прогоны выявили проблемы тестовой среды: недостающие
SSR prefetch/search fixtures, скрытый Suspense fallback при выборе header,
ошибки RSC-запросов при завершении документа в WebKit и непригодное ожидание networkidle.
Перехват ограничен API и внешними адресами; загрузка проверяется по load
и состоянию элементов. Независимые экраны открываются в отдельных документах;
перезагрузка и история вкладок проверяются в одном документе. Проверки ошибок браузера и неожиданных запросов сохранены.

## Ограничения

Это не проверка реального серверного сохранения или реальных платежей.
Физический iPhone, клавиатура, safe area и поворот остаются открытыми.
Короткий редактор не умеет менять фото, предупреждение об отсутствии фото
поэтому не притворяется кнопкой редактирования. Полный сценарий фото относится к UI-03.
Полная визуальная приёмка остальных экранов не заявляется.

Отдельно сохраняются navigationDiagnostics: сообщения WebKit строго о локальных
RSC-запросах только во время server redirect и явного reload. Они не считаются
ошибками сценария, но не удаляются из отчёта. Такие сообщения вне замены документа,
другие pageerror и неожиданные API-запросы завершают тест ошибкой. Это ограничение
автоматизированной проверки, а не доказательство отсутствия любых ошибок Safari.
